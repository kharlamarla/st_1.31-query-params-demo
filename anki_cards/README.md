# 6 типов карточек Anki — жёлто-зелёно-коричневая тема

Спокойная, мягкая для глаз тема (тёплый кремовый фон, коричневый текст, оливковые
акценты) с поддержкой **ночного режима**. Одинаково работает в **Anki desktop (Ubuntu)**
и **AnkiDroid (Android)**. Все типы хорошо дружат с **изображениями** и **формулами**
(встроенный MathJax: `\(x^2\)`, `\[...\]`).

## Что внутри

| Файл | Зачем |
|------|-------|
| `6-card-types-demo.apkg` | Готовый пакет: 6 типов заметок + примеры. **Импортируйте и пользуйтесь.** |
| `styling.css` | Общий CSS темы (день + ночь, шрифты, изображения, кнопки). |
| `templates/` | Исходные HTML лица/оборота — для ручного создания типов. |
| `media/triangle.svg` | Картинка для примера «ответ по изображению». |
| `build_apkg.py` | Скрипт сборки `.apkg` (genanki). |

## Быстрый старт — импорт `.apkg`

**Ubuntu (Anki desktop):** `Файл → Импортировать…` → выберите `6-card-types-demo.apkg`.
Появится колода **«Демо · 6 типов карточек»** и 6 типов заметок с префиксом **«Тема · …»**.

**Android (AnkiDroid):** скопируйте `.apkg` на телефон → откройте его (или в AnkiDroid
`☰ → Импорт`). Либо синхронизируйте через AnkiWeb с десктопа.

Повторный импорт **обновляет** типы заметок (ID зафиксированы), а не плодит дубли.

## 6 типов карточек

1. **Тема · Базовая** — поля `Front`, `Back`, `Image`. Обычная «вопрос → ответ».
2. **Тема · Базовая и обратная** — поля `Front`, `Back`, `Image`. Делает **две** карточки:
   прямую (Front→Back) и обратную (Back→Front).
3. **Тема · Ввод ответа** — поля `Front`, `Back`, `Image`. Вы печатаете ответ, Anki
   показывает посимвольное сравнение.
4. **Тема · Пропуски** (cloze) — поля `Text`, `Extra`. Пропуск задаётся как
   `{{c1::скрытый текст}}`. Можно несколько (`c1`, `c2`, …) — на каждый своя карточка.
5. **Тема · Аудио** — поля `Audio`, `Word`, `Meaning`, `Image`, `Hint`. На лице звучит
   слово, на обороте — слово и перевод. **Свой звук**: в поле `Audio` вставьте
   `[sound:файл.mp3]`. Если `Audio` пустое — слово озвучит **TTS** (см. ниже).
6. **Тема · Выбор ответа** — поля `Question`, `Image`, `Option1..Option4`, `Answer`,
   `Explanation`. До 4 вариантов; пустые скрываются. **Важно:** в поле `Answer` укажите
   **номер** правильного варианта (`1`–`4`). Варианты **перемешиваются** при каждом
   показе; на обороте правильный подсвечивается зелёным, ваш неверный — красно-коричневым,
   и показывается `Explanation` (если заполнено).

## Изображения («отвечать по картинке»)

- В любое поле можно **вставить картинку** прямо в редакторе Anki — она автоматически
  станет адаптивной, по центру, со скруглением и аккуратной рамкой (и в ночном режиме).
- Для типов 1, 2, 3, 6 есть отдельное поле **`Image`** — удобное место для картинки-вопроса
  (например, схема или формула как изображение).
- В типах «Пропуски» и «Аудио» картинку кладите прямо в текстовое поле (`Text` / `Meaning`).

## Звук и TTS

- **Свой файл:** добавьте аудио в карточку (скрепка в редакторе) → в поле появится
  `[sound:...]`. Так звук качественнее.
- **TTS (озвучка текста):** если поле `Audio` пустое, слово из `Word` читает встроенный
  синтезатор. Шаблон использует английский голос: `{{tts en_US voices=...:Word}}`.
  - **Ubuntu:** установлен по умолчанию (на Linux Anki использует системный TTS; при
    отсутствии голосов поставьте, напр., `espeak-ng`).
  - **Android:** TTS-движок обычно уже есть; язык можно доустановить в
    `Настройки телефона → Языки и ввод → Синтез речи`.
  - Для другого языка поменяйте код в шаблоне, напр. `{{tts ru_RU:Word}}`.

## Формулы (MathJax)

Пишите формулы прямо в полях: в строке — `\(a^2+b^2=c^2\)`, блоком — `\[\int_0^1 x\,dx\]`.
Anki отрисует их сам, дополнительной настройки не нужно.

## Ручное создание типа (без `.apkg`)

Если хотите собрать тип руками: `Инструменты → Управление типами заметок → Добавить`,
задайте поля как выше, затем `Карты…` и вставьте содержимое соответствующих файлов из
`templates/` в **Лицевую**/**Оборотную** сторону, а `styling.css` — целиком в поле
**Стилизация**. Для «Выбора ответа» весь блок `<script>…</script>` уже внутри
`6_choice_front.html` — копируйте файл целиком.

## Настройка темы

Все цвета — CSS-переменные в начале `styling.css` (блок `.card { --bg … }` для дня и
`.nightMode … { … }` для ночи). Размеры/жирность шрифтов — классы `.prompt`, `.answer`,
`.meaning`, `.hint`, `.mc-option`. Поменяйте значения и переимпортируйте, либо правьте
прямо в поле **Стилизация** любого типа.

## Пересборка пакета

```bash
pip install genanki
python3 build_apkg.py     # создаст 6-card-types-demo.apkg
```

## Проверка на устройстве

Рендеринг карточек (шрифты, ночной режим, проигрывание TTS, поле ввода, MathJax,
перемешивание и подсветка в «Выборе ответа», картинки) стоит один раз посмотреть прямо
в Anki на Ubuntu и в AnkiDroid после импорта — поведение там может чуть отличаться от
браузера, и это нормально.
