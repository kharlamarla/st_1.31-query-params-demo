# 6 типов карточек Anki — жёлто-зелёно-коричневая тема

Спокойная, мягкая для глаз тема («старый» тёплый жёлтый фон, коричневый текст, оливковые
акценты) с поддержкой **ночного режима**. Одинаково работает в **Anki desktop (Ubuntu)**
и **AnkiDroid (Android)**. Все типы хорошо дружат с **изображениями** и **формулами**
(встроенный MathJax: `\(x^2\)`, `\[...\]`), а на обороте автоматически **прокручивают к
ответу**. У каждого типа есть общие поля **Описание**, **Цитата** и **Код** (подсветка
синтаксиса + нумерация строк) — все показываются на обеих сторонах, если заполнены.

## Что внутри

| Файл | Зачем |
|------|-------|
| `6-card-types-demo.apkg` | Готовый пакет: 6 типов заметок + примеры. **Импортируйте и пользуйтесь.** |
| `styling.css` | Общий CSS темы (день + ночь, шрифты, изображения, кнопки). |
| `templates/` | Исходные HTML лица/оборота — для ручного создания типов. |
| `media/triangle.svg` | Картинка для примера «ответ по изображению». |
| `media/_codehl.js` | Автономная подсветка кода + нумерация строк (работает офлайн). |
| `build_apkg.py` | Скрипт сборки `.apkg` (genanki). |

## Быстрый старт — импорт `.apkg`

**Ubuntu (Anki desktop):** `Файл → Импортировать…` → выберите `6-card-types-demo.apkg`.
Появится колода **«Демо · 6 типов карточек»** и 6 типов заметок с префиксом **«Тема · …»**.

**Android (AnkiDroid):** скопируйте `.apkg` на телефон → откройте его (или в AnkiDroid
`☰ → Импорт`). Либо синхронизируйте через AnkiWeb с десктопа.

Повторный импорт **обновляет** типы заметок (ID зафиксированы), а не плодит дубли.

## 6 типов карточек

1. **Тема · Базовая** — поля `Front`, `Back`, `Image`. Обычная «вопрос → ответ».
2. **Тема · Базовая и обратная** — поля `Front`, `Back`, `Image`. Делает **две** карточки:
   прямую (Front→Back) и обратную (Back→Front).
3. **Тема · Ввод ответа** — поля `Front`, `Back`, `Image`. Вы печатаете ответ, Anki
   показывает посимвольное сравнение.
4. **Тема · Пропуски** (cloze) — поля `Text`, `Extra`. Пропуск задаётся как
   `{{c1::скрытый текст}}`. Можно несколько (`c1`, `c2`, …) — на каждый своя карточка.
5. **Тема · Аудио** — поля `Audio`, `Word`, `Meaning`, `Image`, `Hint`. На лице звучит
   слово, на обороте — слово и перевод. **Свой звук**: в поле `Audio` вставьте
   `[sound:файл.mp3]`. Если `Audio` пустое — слово озвучит **TTS** (см. ниже).
6. **Тема · Выбор ответа** — поля `Question`, `Image`, `Option1..Option4`, `Answer`,
   `Explanation`. До 4 вариантов; пустые скрываются. **Важно:** в поле `Answer` укажите
   **номер** правильного варианта (`1`–`4`). Варианты **перемешиваются** при каждом
   показе; на обороте правильный подсвечивается зелёным, ваш неверный — красно-коричневым,
   и показывается `Explanation` (если заполнено).

## Общие поля: Описание, Цитата, Код

У **каждого** типа в конце есть необязательные поля — заполнять не обязательно, но если
заполнить, они показываются **и на лице, и на обороте**:

- **`Notes` (Описание)** — пояснение/комментарий приглушённым текстом.
- **`Quote` (Цитата)** — выделенный блок-цитата с зелёной полосой слева.
- **`Code` (Код)** — блок кода с **подсветкой синтаксиса и нумерацией строк**. Подсветка
  работает **офлайн** (через `media/_codehl.js`, без интернета), универсальная для
  большинства языков (ключевые слова, строки, комментарии, числа, вызовы функций).
- **`CodeLang`** — необязательная подпись языка над блоком (напр. `Python`, `C++`).

Для формул используйте MathJax прямо в любом текстовом поле (`\(...\)`), а поле `Code` —
для исходного кода.

## Автопрокрутка к ответу

После показа ответа карточка сама прокручивается к блоку ответа (`<a id="answer">` +
небольшой скрипт), чтобы не приходилось листать вручную. Работает в AnkiDroid и на десктопе.

## Изображения («отвечать по картинке»)

- В любое поле можно **вставить картинку** прямо в редакторе Anki — она автоматически
  станет адаптивной, по центру, со скруглением и аккуратной рамкой (и в ночном режиме).
- Для типов 1, 2, 3, 6 есть отдельное поле **`Image`** — удобное место для картинки-вопроса
  (например, схема или формула как изображение).
- В типах «Пропуски» и «Аудио» картинку кладите прямо в текстовое поле (`Text` / `Meaning`).

## Звук и TTS

- **Свой файл:** добавьте аудио в карточку (скрепка в редакторе) → в поле появится
  `[sound:...]`. Так звук качественнее.
- **TTS (озвучка текста):** если поле `Audio` пустое, слово из `Word` читают **два
  голоса** — на лице оно звучит в американском и британском вариантах
  (`{{tts en_US:Word}}` и `{{tts en_GB:Word}}`), а на обороте перевод из `Meaning`
  читается по-русски (`{{tts ru_RU:Meaning}}`). Это разные голоса/языки «из коробки».
  - **Какой язык:** язык задаётся кодом в теге `{{tts КОД:Поле}}` — `en_US`, `en_GB`,
    `ru_RU`, `de_DE`, `fr_FR`, `es_ES` и т.д. Поменяйте код в шаблоне (поле
    **Стилизация → Карты**) под свой язык, либо добавьте ещё строку `{{tts xx_XX:Word}}`,
    чтобы услышать больше голосов.
  - **Конкретный голос:** допишите `voices=` со списком установленных голосов, напр.
    `{{tts en_US voices=Apple_Samantha,Microsoft_Zira:Word}}` — Anki возьмёт первый
    доступный. Список доступных голосов покажет тег `{{tts-voices:}}` на временной карте.
  - **Ubuntu:** на Linux Anki использует системный TTS; при отсутствии голосов поставьте,
    напр., `espeak-ng` или голоса нужного языка.
  - **Android:** TTS-движок обычно уже есть; язык/голоса добавляются в
    `Настройки телефона → Языки и ввод → Синтез речи`.

## Формулы (MathJax)

Пишите формулы прямо в полях: в строке — `\(a^2+b^2=c^2\)`, блоком — `\[\int_0^1 x\,dx\]`.
Anki отрисует их сам, дополнительной настройки не нужно.

## Ручное создание типа (без `.apkg`)

Если хотите собрать тип руками: `Инструменты → Управление типами заметок → Добавить`,
задайте поля как выше (включая общие `Notes`, `Quote`, `Code`, `CodeLang`), затем `Карты…`
и вставьте содержимое соответствующих файлов из `templates/` в **Лицевую**/**Оборотную**
сторону, а `styling.css` — целиком в поле **Стилизация**. Для «Выбора ответа» весь блок
`<script>…</script>` уже внутри `6_choice_front.html` — копируйте файл целиком.

**Для подсветки кода** скопируйте файл `media/_codehl.js` в папку медиа коллекции
(`collection.media`) — на десктопе это `Инструменты → Проверить медиа` покажет путь, либо
просто импортируйте `.apkg` один раз (он принесёт `_codehl.js` сам). Имя начинается с `_`,
поэтому «Проверка медиа» не удалит файл как неиспользуемый.

## Настройка темы

Все цвета — CSS-переменные в начале `styling.css` (блок `.card { --bg … }` для дня и
`.nightMode … { … }` для ночи). Размеры/жирность шрифтов — классы `.prompt`, `.answer`,
`.meaning`, `.hint`, `.mc-option`. Поменяйте значения и переимпортируйте, либо правьте
прямо в поле **Стилизация** любого типа.

## Пересборка пакета

```bash
pip install genanki
python3 build_apkg.py     # создаст 6-card-types-demo.apkg
```

## Проверка на устройстве

Рендеринг карточек (шрифты, ночной режим, проигрывание TTS двумя голосами, поле ввода,
MathJax, автопрокрутка к ответу, подсветка кода с нумерацией строк, перемешивание и
подсветка в «Выборе ответа», картинки) стоит один раз посмотреть прямо в Anki на Ubuntu и
в AnkiDroid после импорта — поведение там может чуть отличаться от браузера, и это нормально.
